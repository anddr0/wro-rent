# Экраны

Вайрфреймы — [screens.webp](screens.webp): сверху клиент, снизу админ.
Это набросок, а не макет: расположение и содержание, без точного дизайна.

## Навигация

- Нижних вкладок нет. Главная — хаб, остальные экраны открываются кнопками.
- Назад — стрелка Telegram в шапке, на всех экранах, кроме главной.
- Главная зависит от роли: клиент видит каталог и свои брони, админ — сводку и разделы админки.
- Дизайн — монохромная тема из tweakcn, светлая или тёмная по Telegram (см. decisions, «Дизайн»).

## Клиент

| Экран               | Адрес                 | Что на нём                                                                | История  |
| ------------------- | --------------------- | ------------------------------------------------------------------------- | -------- |
| Главная             | `/`                   | приветствие, плашка «как это работает», текущие брони, велосипеды, кнопка | К-1, К-6 |
| Выбор велосипеда    | `/bikes`              | все видимые велосипеды: «Подробнее» и «Забронировать»                     | К-1      |
| Карточка велосипеда | `/bikes/[id]`         | фото, описание, цены по тарифам, «Забронировать»                          | К-2      |
| Заявка на бронь     | `/bikes/[id]/book`    | тариф, календарь, время, итог, комментарий, «Отправить заявку»            | К-3, К-4 |
| Заявка отправлена   | `/bookings/[id]/sent` | спасибо, что дальше, сводка заявки, адрес и оплата, «На главную»          | К-5      |
| Карточка брони      | `/bookings/[id]`      | детали брони, «Отменить заявку» или «Написать админу»                     | К-7      |
| История             | `/history`            | прошлые брони; ссылка с главной                                           | К-6      |
| Настройки           | `/settings`           | язык; открывается из меню ⋯ Telegram                                      | В-1      |

На главной у новичка вместо текущих броней — плашка «как это работает».

## Админ

| Экран           | Адрес                  | Что на нём                                                                 | История  |
| --------------- | ---------------------- | -------------------------------------------------------------------------- | -------- |
| Главная         | `/`                    | «Сегодня»: новые заявки, выдать, принять; «Ждут ответа»; разделы           | А-0      |
| Брони           | `/admin/bookings`      | фильтр по статусу и датам, новые сверху                                    | А-6      |
| Карточка брони  | `/admin/bookings/[id]` | клиент и «Написать», даты, тариф, цена, оплата, заметка; кнопки по статусу | А-7      |
| Автопарк        | `/admin/bikes`         | велосипеды, состояние, «Скрыт», «Добавить», ссылка на архив                | А-1, А-5 |
| Велосипед       | `/admin/bikes/[id]`    | название, описание, фото, видимость, архив или удаление                    | А-3, А-4 |
| Новый велосипед | `/admin/bikes/new`     | та же форма, пустая                                                        | А-2      |
| Архив           | `/admin/bikes/archive` | архивные велосипеды, «Вернуть»                                             | А-5      |
| Тарифы          | `/admin/plans`         | список, создать, изменить, скрыть                                          | А-9–А-11 |

Экраны, которые появились при реализации (на вайрфреймах их нет):

| Экран             | Адрес                       | Что на нём                                            |
| ----------------- | --------------------------- | ----------------------------------------------------- |
| Правка брони      | `/admin/bookings/[id]/edit` | цена, депозит, способ оплаты, «Оплачено», заметка     |
| Новый тариф       | `/admin/plans/new`          | название, длительность, цена, «Доступен клиентам»     |
| Тариф             | `/admin/plans/[id]`         | та же форма с данными тарифа                          |
| Настройки проката | `/admin/settings`           | часы работы или «круглосуточно», контакт для клиентов |

Новый велосипед создаётся без фото: после «Добавить» открывается его страница, где фото
загружаются, удаляются и двигаются (каждое изменение сохраняется сразу).

Велосипед и тарифы на вайрфреймах не нарисованы — набросаем, когда дойдём до блоков 5 и 6.
С главной админ может открыть каталог глазами клиента (`/bikes`).

Кнопки в карточке брони админа по статусу:

| Статус              | Кнопки                            |
| ------------------- | --------------------------------- |
| Ожидает             | Отклонить · Подтвердить           |
| Подтверждена        | Отменить · Выдал велосипед        |
| Велосипед у клиента | Принял велосипед                  |
| остальные           | нет, только цена, оплата, заметка |
